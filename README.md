# Google AI Studio 跨对话共享记忆助手

一个给 Google AI Studio（`aistudio.google.com`）用的油猴脚本。

平时在 AI Studio 里每次开新对话，AI 都会失忆，得重新交代一遍自己的背景和要求。这个脚本会在网页左边加一个悬浮小面板，帮你把长期背景存起来，开新对话时自动填进去；聊完还能让 AI 自动从对话里提炼新信息更新到记忆库里。

## 主要功能

- **自动带入记忆**：勾选「自动注入」后，开新对话或发消息时自动把你的背景信息带给 AI，不用每次复制粘贴。
- **按需分组选择**：支持用 `## 标题` 给记忆分段，只勾选当前对话需要用到的那几段（比如写代码时只注入开发环境，不注入无关信息）。
- **AI 帮你整理记忆**：支持三种按钮操作——
  - **提炼增量**：只从当前对话里提取新信息，追加到末尾；
  - **智能合并**：结合当前对话，自动更新或覆盖掉旧的矛盾信息；
  - **整理去重**：清理重复或过时的条目。
  - *注：所有整理结果都会先预览给你看，你点确认后才会真正保存，不会乱改。*
- **防手滑撤销与备份**：自动保留最近 5 个历史版本，改乱了可以一键撤回；支持导出 JSON 文件备份。

## 怎么安装和使用

1. **安装油猴扩展**：确保浏览器里装好了 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. **安装本脚本**：点击本仓库里的 `aistudio-memory-helper.user.js` 文件，再点击页面右上角的 **Raw** 按钮，油猴会自动弹出安装界面，点击「安装」即可。
3. **填入 API Key（用于 AI 自动整理功能）**：
   - 打开 [Google AI Studio](https://aistudio.google.com/)，点击左侧新出现的记忆悬浮窗，切到 **「设置」** 标签页；
   - 填入你自己在 Google AI Studio 免费申请的 Gemini API Key，点击「保存设置」即可。
   - *如果只用“手动编辑记忆 + 自动注入”，不填 Key 也能用。*

## 隐私与说明

- **本地存储**：你的所有记忆内容和 API Key 都只保存在你自己的浏览器本地，不会上传到任何第三方服务器。
- **关于代码与维护**：本项目由个人提出需求并实测调通，代码主要由 AI 生成。由于 Google AI Studio 网页改版较快，不保证长期同步更新；如果后续页面改版导致失效，欢迎自行 Fork 修改。
